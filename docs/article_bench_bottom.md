# axiom-battle：从谷底出发的开源项目

**如果你正在经历谷底，这个项目是认真的。**

---

## 它是什么

`axiom-battle` 是悟道体系公理对抗赛的代码实现——八个悟道公理（生长、光影、色彩、布局、叙事、边界、自由、因果）互相攻击验证，用 Popper 证伪主义判断哪个公理"死"了。

不是玩具，是有完整论文支撑的认知框架。
不是概念，是可以 `pip install` 的代码。

```
pip install git+https://github.com/zhouhailiang0116/axiom-battle.git@v0.1.0
```

历史上所有从谷底爬起来的人，都做对了同一件事：**在废墟中快速认出最小可用资产。**
